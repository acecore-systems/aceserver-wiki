生活鯖では、`/shop open`でショップを開き、対象の食料や石材を売却できます。以下は[Discordの公式掲示板](https://discord.com/channels/737538781024092170/779569416438415421/1549002580707901481)に掲載された**売却価格**です（2026年9月16日編集時点）。単位は掲示板の表記どおり`pt`です。

| 品目 | 売却価格 |
| --- | --- |
| キノコシチュー、ビートルートスープ | 1個あたり30pt |
| 牛・豚・鶏の生肉 | 64個あたり30pt |
| 小麦、ビートルート | 64個あたり15pt |
| ニンジン、ジャガイモ | 64個あたり10pt |
| ネザーウォート | 64個あたり30pt |
| 石、丸石、砂利 | 64個あたり10pt |
| 深層岩、深層岩の丸石 | 64個あたり20pt |
| 閃緑岩、花崗岩、安山岩 | 64個あたり30pt |

対象品や価格は変更される場合があります。売却する前に[Discordの掲示板](https://discord.com/channels/737538781024092170/779569416438415421)で最新の表を確認してください。ショップの追加案内は[2026年9月14日のお知らせ](https://discord.com/channels/737538781024092170/774152638450237460/1549002055472123917)にあります。

## ショップを開けないとき

コマンドは`/shop open`だけを入力し、後ろに空白を付けないでください。2026年9月25日に「Category」を求められるエラーが報告された際の[スタッフの案内](https://discord.com/channels/737538781024092170/868073783771144192/1552922636885950607)です。その報告は同日に解決していますが、同じ症状が続く場合は[スタッフへの質問・問合せ](https://discord.com/channels/737538781024092170/868073783771144192)で状況を伝えてください。
