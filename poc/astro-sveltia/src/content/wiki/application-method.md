各種申請は、公式Discordで認証を終えてから、該当する窓口の最新の案内と書式に従ってください。個人の申請内容やサーバーアドレスはWikiに転載しません。

| 用件 | 窓口 |
| --- | --- |
| 大規模建築の保護 | [大規模建築保護申請](https://discord.com/channels/737538781024092170/1085879300709961799) |
| チャット辞書への追加 | [チャット辞書申請](https://discord.com/channels/737538781024092170/1099346896541192222) |
| コンセプト鯖の提案 | [コンセプト鯖設立案内](/article/concept-server-guide/)と[提案チャンネル](https://discord.com/channels/737538781024092170/1461900550768562206) |
| 一般的な質問 | [スタッフへの質問・問合せ](https://discord.com/channels/737538781024092170/868073783771144192) |
| 個別の調査・相談 | [個別お問い合わせフォーム](https://discord.com/channels/737538781024092170/898399259148304414) |

一部の申請チャンネルは、認証・権限を得るまで表示されません。どの窓口か迷う場合は、スタッフへの質問・問合せを利用してください。
