コンセプト鯖は、プレイヤーの要望に基づき、特定のコンセプトで長期的にMinecraftを遊ぶためのサーバーです。短期で完結するMOD PvP、期間限定の戦争鯖、コンテストなどは、コンテンツ部門へ相談してください。

## 設立と運用の条件

- 長期の目安は1か月以上です。提案後、参加希望者が5人以上いる場合に新規設立できます。
- 1か月のアクティブユーザーが5人未満になると、稼働が停止される場合があります。停止後も、要望と状況に応じて一時的または長期的に再開される場合があります。
- 選択できるサーバーソフトウェアはPaper MC、Fabric、Forge、NeoForgeです。特に希望がなければPaper MCを使用します。ほかのソフトウェアは相談のうえ、正常にマルチプレイできるか確認して可否が判断されます。
- MODはサーバーだけに導入する方式を推奨します。クライアントにも導入が必要なMODを使う場合、統合版の参加者が入れなくなることがあります。
- 他のサーバーとアイテムを共有できません。専用通貨や共通通貨を設定でき、アイテムやプレイヤーのタグの売買に利用できます。希望があればエースコインからの流入を設定できますが、エースコインへの流出は慎重に検討されます。

## 提案の流れ

1. [コンセプト鯖提案の部屋](https://discord.com/channels/737538781024092170/1461900550768562206)に、企画の内容を投稿します。下の項目は考える際の参考で、ピン留め案内ではテンプレートの使用は任意です。
2. 興味がある人は提案に⭕のリアクションを付けます。投稿者自身も付けてください。
3. 賛同5人を目安にチケットを発行し、**提案メッセージのリンク**を運営に送ります。投稿者を5人の人数に含めるかは案内に明記されていません。
4. 設立ルールに沿って、チケットで下の項目を詳しく伝えます。運営が実現可能性を審査し、参加希望者へのアンケートを行います。
5. 設立条件を満たした場合、サーバーを準備し、専用のDiscordテキストチャンネルを設置します。提案部屋での賛同だけで設立が確定するわけではありません。

提案部屋の投稿ではテンプレートは任意です。正式なチケットでは、設立ルールにある次の項目をまとめてください。

| 項目 | 記入する内容 |
| --- | --- |
| サーバー名 | コンセプトのイメージが伝わる名前 |
| 使用サーバー | Paper MC、Fabric、Forgeなど |
| サーバーバージョン | 希望するバージョン |
| 使用MOD・プラグイン | 使うもの。ない場合は「なし」 |
| サーバーの概要 | ルールや遊び方など、決まっている内容をできるだけ詳しく |
| 想定期間 | 1か月、3か月以上など |
| 設立にかかわるメンバー | 設立までの打ち合わせに参加する人 |

## オーナーとサブオーナー

提案者がオーナーになります。オーナーは専用Discordチャンネルの管理、サーバー内や利用者からの質問への対応、ルールの制定・改定、サブオーナーやモデレーターの指定を行います。基本的にサーバーOPが付与されます。

サブオーナーとモデレーターにもサーバーOPが付与されます。サブオーナーはオーナーと同じ権限を持ち、オーナーがサーバーを離れる場合はオーナーに昇格します。

## サーバーの終了

アクティブユーザーの減少やオーナーの希望により、次のいずれかの状態になります。

- **凍結**：常時起動を停止します。再開できますが、運営判断でアーカイブ化される場合があります。
- **アーカイブ化**：Discordチャンネルは書き込み不可となり、アーカイブへ移されます。アーカイブ化後はチャンネルもサーバーも再開できません。

## 提案できないコンセプト

実在の宗教や現実の政治に関わるもの、特定の人物やプレイヤーを貶めるもの、サーバーに危害を加えるもの、運営を妨げるものは禁止です。性的・わいせつな表現、過度な暴力・残虐な描写、グロテスクな表現、その他社会通念上不適切な表現を目的とするものも禁止です。
