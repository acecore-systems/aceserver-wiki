## プラグイン一覧

| プラグイン名 | 説明 |
| --- | --- |
| [CoreProtect](https://www.spigotmc.org/resources/coreprotect.8631/) | ブロックの設置や破壊などのログを記録します。 |
| [GSit](https://www.spigotmc.org/resources/gsit-modern-sit-seat-and-chair-lay-and-crawl-plugin-1-13-x-1-19-x.62325/) | ハーフブロックや階段に座れます。 |
| [LockettePro](https://www.spigotmc.org/resources/lockettepro-for-1-14-1-15-1-16.74354/) | チェストに鍵を掛けます。 |
| [LuckPerms](https://luckperms.net/) | コマンド権限を管理します。 |
| [LunaChat](https://www.spigotmc.org/resources/lunachat.82293/) | ローマ字発言を自動日本語化するなどチャットを補助します。 |
| [OpenInv](https://dev.bukkit.org/projects/openinv) | 管理者がチェストやインベントリを確認します。 |
| [RHLeafDecay](https://www.spigotmc.org/resources/%E2%98%84%EF%B8%8F-rhleafdecay-fast-and-smooth-leaf-decay-1-13-x-1-19-x.83581/) | 破壊した原木にくっついていた葉を自動で破壊します。 |
| [SimplePortals](https://www.spigotmc.org/resources/%E2%8D%9F-simple-portals-%E2%8D%9F-effective-regional-portals-bungeecord-compatible.56772/) | サーバー間で移動できるゲートを作成します。 |
| [worldedit](https://dev.bukkit.org/projects/worldedit) | 大規模な地形操作をします。 |
| [WorldEditSelectionVisualizer](https://www.spigotmc.org/resources/worldeditselectionvisualizer-1-7-10-1-19.17311/) | 「worldedit」の操作を補助します。 |
| [worldguard](https://dev.bukkit.org/projects/worldguard) | 地形を保護します。 |
| [RecipeManager](https://dev.bukkit.org/projects/recipemanager) | レシピを追加します。 |
